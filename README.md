# UniSync — Full-Stack Campus Hub (Node.js + SQLite)

## Quick Start
1. Ensure **Node.js (v18+)** and **Python 3** (built-in `sqlite3`) are installed.
2. Run:
   ```bash
   node server.js
   ```
3. Open **http://localhost:3000** in your browser.

`unisync.db` (SQLite) is automatically created and seeded on first run. Uploaded files are saved under `uploads/`.
